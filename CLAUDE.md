# Mockup Studio

Fullscreen Three.js iPhone mockup. Shows mobile screens (images/video, carousel with transitions) on a procedural iPhone, a camera cinematic (saved shots + presentation mode), HDRI lighting, PNG / MP4 / WebM export. Installable PWA that also works offline.

## Layout
- `index.html` — markup + importmap + `<script type="module" src="js/main.js">`.
- `css/` — `tokens.css` (design tokens: `:root`, palette, type, motion, Tweakpane theme) · `main.css` (layout + components, consumes tokens) · `export.css` (export card, shared segmented/slider controls) · `shoteditor.css` (cinematics card) · `notices.css` (persistent notices) · `fonts.css` (generated by `tools/vendor.mjs`).
- `js/` — ES modules, one responsibility per file:
  - `core/` utils (`$`, `EASE`, `DUR`, `toast`) · params (`P`) · persist · hooks (bridge to the UI, avoids import cycles) · history (undo/redo of settings + shots) · notice (persistent notices) · pwa (service-worker registration) · **strings (`T`: every user-facing message generated from JS)**
  - `three/` renderer · scene · hdri · metal · iphone · screen · smudge · camera (shots, presentation, `commitShots`) · loop · quality (Auto/High/Max) · accum (progressive jitter accumulation) · glcontext (WebGL context loss/restore) · **formats** (`FORMATS`, `exportSize`) · **frame** (panel state, export guide, thirds grid, `layout`, `beginExport/endExport`) · **session** (`recording`/`exporting` flags, pixel ratio, `setRenderSize`, `setQuality`)
  - `screens/` carousel · examples · load (files → screens, limits) · store (IndexedDB persistence of the user's screens)
  - `ui/` pane.js (entry; builds the Tweakpane panel from `ui/pane/*`: scene, phone, screens, camera, ui, shared) · strips (dock: screens bar, play toggle) · dockToggle · device (phone/tablet model switch) · onboarding · exportcard · shoteditor (cinematics card) · shotbar (timeline while playing) · quality · touch (double-tap re-frame, touch controls)
  - `export/` export (PNG, `offer()`) · offline (frame-by-frame video) · videosync (sync source videos to the virtual clock) · project (JSON v3 project, import/validation)
  - `data/` minimal manifests (no base64): `examples-data.js` → `assets/examples/ex-01.jpg…` (original JPEGs, not re-encoded) · `smudge-map.js` → `assets/smudge-map.jpg`.
  - `main.js` — load order + Boot.
- **Left rail** (`#rail`, top→bottom): Help (onboarding) · Cinematics editor · Controles avanzados (the Tweakpane panel, titled «Controles avanzados») · Dock toggle (second to last) · Export (last). There is no Play button in the rail: play/stop lives in the cinematics card (accent button, `hooks.shotEditorPlay`) and the `Space` key. Cards (onboarding, export, cinematics) anchor to its right and are mutually exclusive. Dock visibility = `P.ui.dock` (key `P`), **hidden by default** (`<body class="dock-hidden">` so it never animates out at load; transitions turn on with `body.ui-ready`), independent of the advanced panel, which is hidden entirely when collapsed.
- **Cinematics card** (`js/ui/shoteditor.js`, 420 px): list of shots, each row with its own icons (update · duplicate · rename · delete → `.se-ri[data-act]`; reorder = drag the grip or ↑/↓ on it — there are no Up/Down/Copy-JSON buttons). Detail tabs in order **Global · Toma**: Global = Move · Hold · **Zoom** (`P.cam.zoom`, moved here from Camera › Lens) · Loop · Random. Bottom actions: preset selector + Cargar, then Reproducir cinemática (accent, `clapperboard` icon — same icon as the rail button), then Guardar cámara.
- **Export card** (`js/ui/exportcard.js`): PNG | Video tabs sit at the top (under the title, `P.exp.kind`); each tab shows its own data (PNG: Escala/Alpha/Sombra · Video: Duración/FPS/Mbps/Codec/Modo/Shots). Main button is accent with icon (`camera` / `video`) like Reproducir cinemática; in Video a hint suggests trying Realtime mode if the export fails.
- **Carousel scroll**: screens with `autoScroll` (tall designs) wait `Delay`, scroll down and scroll back up (yoyo) inside the `Hold` time, so the next screen's transition starts from the top (`scheduleCar` in `screens/carousel.js`).
- **Keyboard shortcuts** (`js/screens/load.js`; ignored while typing in inputs): `Space` play/stop the cinematic · `H` hide/show the whole UI (`js/ui/uiToggle.js`, `body.ui-hidden`, opacity fade, temporary) · `G` hide/show both guides (thirds grid + frame/dim; `hooks.toggleGuides` in `ui/pane/ui.js`, keeps the panel's Grid/Frame switches in sync) · `P` screens panel (dock; was `D`) · `S` save shot · `←/→` screens · `Ctrl+Z` / `Ctrl+Shift+Z` undo/redo. The cinematics card opens on the **Global** tab.
- **Device model** (`#devSw`, `js/ui/device.js`): bento block to the right of the dock (same height via `--dock-h`, hides with the dock; on mobile a icon-only pill above it). Two options, Celular / Tablet, stored in `P.phone.device` (`phone` | `tablet`, undoable, persisted). Functionally identical — only the measures change: `DEVICES` in `three/iphone.js` (`PW/PH/PD/BEZEL/B/INSET/rK`, exported as live `let` bindings reassigned by `setDims()`), `applyDevice()` in `three/smudge.js` rebuilds shapes/buttons/pose/prop, the island is hidden on tablet (`syncIsland`). Items with default framing are re-fitted (`reframeDefaults`). `suggestFor()` (called from `loadBlobs`) shows a tooltip above both options when the loaded screens' orientation (aspect > 1 = landscape, majority wins) contradicts the active model. `body.dev-tablet` switches the dock thumbnails to 16/10. The "tablet" model is shaped like a MacBook Pro display (16:10, symmetric thin bezel, no side buttons; key kept as `tablet`, label «Tablet»). Tablet camera shots are not re-derived: landscape export formats (16:9) frame it best.
- A `let` reassigned from another module exposes `setX(v)` (e.g. `setCur`, `setShots`). Low layers call the UI through `hooks.*` to avoid circular imports (TDZ errors).
- No build step. Run `npm start` (static server on :5173). Do not open via `file://`.

## Stack (vendored in `vendor/`, no CDN at runtime)
Three r165 (0.165.0) (OrbitControls, RoundedBoxGeometry, EffectComposer, GTAOPass, EXRLoader) · GSAP 3.12.5 · Tweakpane 4.0.4 + plugin-essentials 0.2.1 (buttongrid, fpsgraph) · Lucide 0.460.0 · mp4-muxer 5.1.3 / webm-muxer 5.0.3 (WebCodecs export). The importmap and `<script>` tags point at `vendor/…`; licenses in `vendor/licenses/`. Fonts (Bricolage Grotesque, Inter, JetBrains Mono; woff2 latin + latin-ext) in `vendor/fonts/` via `css/fonts.css`.
- **Regenerate vendor/** (versions pinned in `tools/vendor.mjs`, dependency-free Node): `node tools/vendor.mjs` (or `--only=three,libs,licenses,hdri,fonts`). To bump a version: change the constant, regenerate, update the importmap if paths change and bump `CACHE_VERSION` in `sw.js`. PWA icons: `python tools/make-icons.py` (Pillow).
- **HDRI**: only the default (`hall`, `P.env.preset`) lives in `vendor/hdri/`; the rest come from `@pmndrs/assets@1.7.0` (CDN) on demand and the service worker caches them at runtime (`mockup-studio-hdri`). Offline and uncached → toast and the current HDRI is kept.
- **PWA / offline**: `manifest.webmanifest` + `sw.js` (versioned precache `mockup-studio-vN`; cache-first for vendor/assets/fonts, stale-while-revalidate for js/css/index). Registered in `js/core/pwa.js` only in production or with `?sw=1`; on plain localhost it is NOT registered and a previous one is unregistered. **After adding/removing files in js/, css/, vendor/ or assets/ run `node tools/sw-list.mjs`** (regenerates `PRECACHE`; `tests/offline.test.mjs` fails if it is stale) and bump `CACHE_VERSION` when publishing. To try it: `npm start` → open `http://localhost:5173/?sw=1`, DevTools > Application > Service Workers, tick Offline and reload.
- **Data assets**: to change an example screen replace the file in `assets/examples/` (same name) or edit the manifest. `tools/extract-examples.py` was the one-off base64 → files migration.

## Code map (one module each under js/)
Parameters `P` (single source of truth) → Persistence (`localStorage` key `mockup-studio:v2`, throttled save; user screens in IndexedDB `mockup-studio-screens`) → Renderer + postprocessing (RenderPass → GTAO → OutputPass → accumulation pass → grade ShaderPass) → Scene → HDRI loader (rotation, normalization, derived key light) → procedural iPhone (superellipse body, layers Z_FRONT/SCREEN/ISLAND/GLASS) → Screen shader (carousel, parallax) → Glass smudge → Carousel → Camera shots (`camTween`, `cutTo`, `SHOT_PRESETS`, per-shot `move`/`hold`/`ease`) → formats / frame / session → Render loop (+ quality, accum) → Tweakpane (`ui/pane/*`) → Strips → Cards (onboarding, export, cinematics, timeline) → Export → Offline video (+ videosync) → Project JSON → History → Boot.

## Conventions
- **Vocabulary**: *cinemática* = the whole sequence; *toma* = each saved camera angle. Never "shots" in user-facing Spanish text. Every message generated from JS lives in `js/core/strings.js` (`T`); `tests/strings.test.mjs` fails on a literal passed to `toast`/`toastOnce`/`showNotice`/`confirm`. Static text in `index.html` is not centralized.
- UI language: **English, one word or acronym** for every Tweakpane label/option. Related controls grouped in tabs (5 folders: Scene, Phone, Screens, Camera, UI). The cards (onboarding, export, cinematics, dock) use short Spanish labels, Inter for text and Bricolage Grotesque for figures/titles. Keep the panel compact.
- Animations: `expo.inOut`, 850 ms (`EASE`, `DUR`) for layout/transforms; **fades are opacity-only** (`power2.out` in, `power2.in` out, no Y movement).
- Design: Swiss/editorial, neutral greys, **no borders/strokes on controls** (tonal fill instead; 1px `--line` only as a section separator), no shadows, bento floating panels (`--gap 12px`, `--radius 18px`), tokens only (no hardcoded colors; `--black`/`--white` exist for blend/dim). Cards have fixed height so they never jump when content changes. The Controls panel is a solid `--paper-2` block (no transparency/blur); cards use `--paper-2` 94 % + blur.
- Hover styles only inside `@media (hover:hover)` (no sticky hover on touch); tooltips via `data-tip` (rail, icon buttons).
- Shaders: explain with comments.
- Grid (thirds) draws over the active frame (full viewport for `Pantalla`, via `gridRect`; `guide` stays null for `Pantalla` and is the export rect), `mix-blend-mode:difference` in its own node (a child of `#guide` would not see the canvas). Hidden while the cinematic plays (`body.pres-playing`) and while recording; `no-grid` is the user toggle.
- Quality: `P.quality.mode` auto · **medium** (stable ≈ 40 fps: one-time calibration of K = fps·pixels·pr², cached in `localStorage` `mockup-studio:medium-k`, then locked; recomputed from K on window resize; AO 8 samples, no preview accumulation, PNG 8 samples — `tests/quality-medium.test.mjs`) · high · max. Auto = (adaptive pixel ratio only while moving; every resolution change is a visible flicker, so it only steps UP when the predicted FPS at the higher resolution stays ≥ 45 × 1.3 — see `tests/quality-auto.test.mjs`) · high · max. PNG export accumulates jittered samples (8/12/16 by mode); the export path is independent of the preview quality.
- Exports: every downloaded file gets a random 5-char code (`offer()` → `name-XXXXX.ext`). Default format 9:16; PNG/Video kind persists in `P.exp.kind`.
- Video export must restart the carousel at image 1; offline mode = frame-by-frame with a virtual GSAP clock; source videos are paused and seeked to the virtual time (`videosync.js`).
- Persist new params through `P` so they save/import automatically; "UI · temporal" values (`UI_TMP`) are intentionally not saved. Project JSON is `version:3` (settings + shots + screens; videos > 25 MB are skipped with a notice); v2 still imports.
- Every mutation of `shots` goes through `commitShots` (camera.js) → `hooks.onShotsChange(reason)` → undo/redo (`core/history.js`). Settings are recorded from the Tweakpane `change` event (internal refreshes are ignored via `syncing`/`applyingPreset`).

## Testing
- `npm test` runs every `tests/*.test.mjs` (own static server + headless Chrome with software WebGL via `playwright-core`; `tests/helpers.mjs`). Run one: `node tests/<name>.test.mjs`. UI tests need `gsap.ticker.lagSmoothing(0)` after `boot()`; software WebGL runs ~1 fps, so wait for state ("advances within N s") instead of fixed windows, and disable CSS transitions when measuring colors.
- Structural guards: `refactor-pane` (Tweakpane structure fingerprint in `tests/fixtures/pane-structure.json`), `refactor-format` (export surface of formats/frame/session), `strings`, `offline` (precache list).
- `node tools/unused.mjs` writes `tools/unused-report.md` (unused exports/imports/CSS, dead hooks, stale comments). Test-only exports (`info`, `limits`, `snap`, `commitShots`, `glLost`, `videoSyncActive`) are intentional test seams.

## Gotchas
- Social preview (Open Graph / X card) lives in `index.html`: title, 130-char description and the README header image (`ref/67ab…png`, 1920×1010). `og:image` MUST be an absolute public URL (crawlers don't resolve relative paths): it points at the GitHub raw file; when a production domain exists, switch it to `https://<domain>/ref/….png` and add `og:url`/canonical. Guarded by `tests/social.test.mjs`.
- `scheduleCar()` needs ≥ 2 screens to arm the auto-advance: examples load in the background after the first one, so `main.js` calls `scheduleCar()` again when they arrive (regression test in `tests/examples.test.mjs`).
- `downloads` artifact capability exists only inside claude.ai; outside it `offer()` falls back to a modal/anchor download — test PNG + video locally.
- Headless testing uses Swiftshader: inject `gsap.ticker.lagSmoothing(0)` so timings are real; `requestAnimationFrame` can be very slow there (don't depend on it for UI state).
- Glass/island/screen are excluded from the GTAO G-buffer via an `overrideVisibility` wrapper; don't reintroduce a 2D AO mask.
- Shape: `rrShape` point list must not repeat the closing point (breaks bottom geometry).
- The PCSS shadow loops use `textureLod(..., 0.0)` (no implicit derivatives); a benign `X4000` ("potentially uninitialized variable getShadow") warning from the injected chunk may still appear on D3D/ANGLE and is harmless.
- `VideoTexture` is created without mipmaps by three; `carousel.js` enables `LinearMipmapLinearFilter` for videos (otherwise high-res video aliases badly on the small tilted screen).
